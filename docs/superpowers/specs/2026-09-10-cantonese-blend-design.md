# Cantonese Character Blend — Design Spec

Date: 2026-09-10
Status: Approved for planning
Extends: `2026-09-10-cangjie-trainer-design.md` (character sets section)

## Purpose

The trainer's 10 sets currently rank characters by a Taiwan written-text corpus, so the characters that written Cantonese depends on (嘅 唔 係 佢 咗 啲 嗰 喺 咁 哋 冇 嘢 睇) are absent. Cantonese writers should meet them in the same frequency ladder, not in a side list. This change re-ranks all 1000 characters by an equal-weight blend of Hong Kong written Chinese and spoken Cantonese, generated by a committed, reproducible script.

## Requirements

### Sources

- **Written:** 八、九十年代香港字頻統計, the Hong Kong 1980s–90s character frequency table from the CUHK Chinese Character Frequency Statistics for Hong Kong, Mainland China and Taiwan, `https://humanum.arts.cuhk.edu.hk/Lexis/chifreq/chifreq.php?year=90&place=hk&sort=no&method=1`. Big5-encoded HTML table; the character is the first cell and the raw count (頻次) is the fifth.
- **Spoken:** the Hong Kong Cantonese Corpus (HKCanCor), Luke K. K. and Wong M. L. Y. (2015), CC BY 4.0, UTF-8 zip at `https://raw.githubusercontent.com/fcbond/hkcancor/master/data/hkcancor-utf8.zip`. Transcript token lines have the form `word/pos/jyutping/`; tokens whose part of speech is `w` (punctuation) are skipped; every Han character in every remaining token counts once.

### Blend

1. For each corpus, count Han characters (`\p{Script=Han}`) and convert counts to a per-million rate: `count / corpusTotal * 1_000_000`.
2. Apply the normalization table to the spoken corpus before counting. HKCanCor spells several particles and pronouns with one fixed character per Jyutping syllable; typed Cantonese uses different characters, so the corpus forms merge into the typed forms:

   | corpus form | Jyutping | typed form |
   |---|---|---|
   | 噉 | gam2 | 咁 |
   | 囖 | lo1 | 囉 |
   | 𡃉 | gaa3 | 㗎 |
   | 哩 | ni1 | 呢 |
   | 揾 | wan2 | 搵 |
   | 吖 | aa1 | 呀 |
   | 喇 | laa1 | 啦 |
   | 嚹 | laa3 | 喇 |

   Mapping is a single lookup per character, so 嚹 becomes 喇 and stops there. Two paralinguistic fillers the transcribers wrote as characters, 喀 (haak6 backchannel) and 誒 (e6 hesitation), are not counted from the spoken corpus at all, because nobody types them.

3. Blended score = `0.5 * writtenRate + 0.5 * spokenRate`. A character absent from one corpus contributes 0 from that side.
4. Drop any character outside the Basic Multilingual Plane (code point above U+FFFF) so every character is reachable on a standard Cangjie keyboard.
5. Sort by blended score descending, ties broken by written rate descending then code point ascending, and take the first 1000.

### Output

- `src/data/sets.ts` keeps its exact shape: `SET_SIZE`, `SET_COUNT`, `CHARACTERS` as ten concatenated 100-character string literals, `SETS` sliced from it. Only the literal and the doc comment change.
- The doc comment names both sources, the weight, and the normalization table, and says the file is generated by `scripts/build-characters.mjs`.

### Script

- `scripts/build-characters.mjs`, plain Node (ESM), no dependencies beyond Node built-ins. Node ships TextDecoder with Big5 support, so no extra package is needed for decoding.
- Downloads both sources into a git-ignored `data-sources/` directory if they are not already present, so re-runs are offline.
- Prints a short summary: character counts per corpus, the first 20 characters, and the ranks of 嘅 唔 係 咗.
- `npm run build:characters` runs it.

### Tests (`src/data/sets.test.ts`)

- Existing: exactly 1000 characters, no duplicates, Han only, 10 sets of 100 in order, `SETS.flat().join('') === CHARACTERS`.
- Changed: the first character is `係`.
- Kept: the nine written anchors `般標素適專參注溫餘` are present; the rare characters `硯壺蟻嶼蝶蜂莓醋襪嗽` are absent.
- New: the Cantonese anchors `嘅唔係佢咗啲嗰喺咁哋冇嘢睇` are present.
- New: every character is in the Basic Multilingual Plane.

## Error handling

- The script exits non-zero with a clear message if a download fails, a decoded table yields fewer than 3000 characters, or the corpus zip yields fewer than 50 transcript files. It never writes a partial `sets.ts`.
- The generated file is validated by the same test suite; a bad regeneration fails `npm test`.

## Testing

- Unit tests above on the generated data.
- The script itself is exercised by running it once during implementation and committing its output; its parsing logic is small enough that the data tests are its acceptance test. No network calls in the test suite.

## Out of scope

- Per-set labels distinguishing Cantonese characters.
- Jyutping or pronunciation hints.
- A user-facing toggle between Mandarin-written and Cantonese rankings.
